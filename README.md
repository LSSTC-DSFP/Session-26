# Session-26

The twenty-sixth session of the LSST Discovery Alliance Data Science Fellowship Program focuses on scientific communication and data visualization. Session 26 will be held at UC San Diego.

Guest instructors for Session 26 are:

- Dr. Lucian Walkowicz, JustSpace Alliance [:octocat:](https://github.com/lmwalkowicz)
- Dr. Paul Rosen, University of Utah [:octocat:](https://github.com/PaulRosenPhD)
- Dr. Aaron Geller, Northwestern [:octocat:](https://github.com/ageller)

Lectures were also delivered by the DSFP leadership team:

- Dr. Adam Miller, Northwestern | CIERA [:octocat:](https://github.com/adamamiller)
